# 影片摘要與分析指令 (Prompt)

請根據提供的 YouTube 語音轉文字稿（Transcript）進行摘要與分析整理。

## ⚠️ 重要注意事項 (Critical Warning)
> **由於提供的文本是經由語音識別工具（Whisper）自動轉換產生的，內容中可能包含錯別字、漏字或同音異義詞。**
> 在進行分析與解讀時，請務必發揮你的理解能力，根據上下文進行合理推斷與自動糾錯，請特別留意財經術語、公司名稱與數字，避免因識別錯誤而產生誤解。

### 🔑 關鍵詞彙表（優先參照）
> **在糾正語音辨識錯誤時，請務必優先參照 `docs/keywords.md` 關鍵詞彙表。**
> 該詞彙表收錄了本頻道歷次直播中最常出現的股票名稱、財經術語、人名及其對應的英文與股票代碼，並列出了 Whisper 常見的誤識別模式。
> 例如：「肺斑」→「費半」、「沙姑值」→「殺估值」、「配螺旭」→「佩洛西」等。
> 請在分析前先載入該詞彙表，以此作為糾錯的第一優先依據。

## 📐 輸出格式（嚴格遵守模板）
> **生成 `summary.md` 時，請嚴格遵照 `skills/templates/summarize_template.md` 的結構與格式規範。**
> 模板檔案內的 HTML 註解（`<!-- ... -->`）包含了各區塊的詳細撰寫規範，請務必閱讀並遵守。
> 不得自行變更區塊順序、emoji、標題層級或表格欄位標題。

## 任務要求
1. **基本資訊**：在摘要的最上方，請務必包含以下資訊（若有提供或可從檔案名稱/中繼數據中推斷）：
   - **影片標題**：
   - **影片日期**：
   - **影片 URL**：
2. **H1 標題格式**：
   - 小翠時政財經的影片：`# 📊 影片摘要與投資分析報告：小翠時政財經 — {{影片類型}} ({{影片日期}})`
     - 例：`# 📊 影片摘要與投資分析報告：小翠時政財經 — 會員直播 (2026-07-31)`
     - 例：`# 📊 影片摘要與投資分析報告：小翠時政財經 — 每日要聞 (2026-07-31)`
   - 美投君的影片：`# 📊 影片摘要與投資分析報告：美投侃新聞 ({{影片日期}})`
3. **內容總結**：請以繁體中文撰寫一份簡潔明瞭的摘要，說明這段影片的核心主題、市場分析視角與最終結論。本摘要僅需針對當下影片本身的內容進行分析，請**不要**在此處進行跨頻道或跨集數的對比。**注意：在總結與後續分析中，請完全排除影片內的「工商內容」（贊助廣告、推廣等），不予列入摘要。**
4. **關鍵重點整理**：請以編號列表（1. 2. 3. ...）搭配 **粗體小標題** 列出講者提到的重要話題、邏輯推演與觀點。**不得使用 `###` H3 標題。**
5. **觀眾答疑與互動（專屬小翠頻道）**：
   - 若文本為「小翠時政財經」頻道的影片，且內容中包含觀眾投稿回覆、留言朗讀或答疑環節，請在【`## 🔍 關鍵重點整理`】之後、【`## 📊 投資與市場數據提取`】之前，插入「`## 🗣️ 小翠讀評`」章節。
   - 若為美投君的影片，則省略此章節。
   - **不需要逐字紀錄**，概括提問與小翠回覆的大意即可。
6. **投資與市場數據提取（如有）**：
   - 若文本中提及特定股票名稱、板塊、代碼、價格、本益比（PE）、每股盈餘（EPS）等財務數據或預測，請將其整理成易讀的**表格**。
   - 表格欄位標題固定為：`| 股票 / 資產名稱 (繁體中文) | English Name | Ticker | 財務數據 / 市場表現 | 講者觀點與看法 |`（不得變更）。
   - 並在表格旁附註講者對該資產/數據的看法（如：強烈看好、看好、中性、看壞、警告等）。
   - **股票名稱請同時標註繁體中文與英文名稱及代碼**，可參照 `docs/keywords.md` 取得正確對應。
7. **維護與更新關鍵詞彙表**：
   - 每次完成摘要與分析後，請回顧本次文本中是否出現了新的高頻錯誤辨識（如新的公司名、人名被錯認），或是新的專業財經術語。
   - 若有發現，請主動更新 `docs/keywords.md` 檔案，將新的誤識別模式與正確用詞追加至對應的分類表格中，持續提升未來的糾錯準確度。

請將最終分析結果輸出為結構化的 Markdown 格式（如 `summary.md`），嚴格遵照 `skills/templates/summarize_template.md` 的格式。
